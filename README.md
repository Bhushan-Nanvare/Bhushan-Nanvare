## 🚀 Featured Projects
### 🧠 [CodeMind-RAG](https://github.com/Bhushan_Nanvare) — AI Code Search Engine
> **Python · FastAPI · TypeScript · Next.js 14 · Qdrant · LangChain · HuggingFace**

A semantic code search engine that answers natural language questions about GitHub repositories using a hybrid RAG pipeline.

- 🔍 Hybrid search: semantic understanding + keyword matching
- 🧩 Language-aware code chunking via LangChain for context preservation
- 🔄 Async ingestion pipeline with real-time progress tracking
- 📦 Supports large-scale repository indexing into Qdrant vector DB

---

### 👥 [MultiCoder](https://github.com/Bhushan_Nanvare) — Real-time Collaborative Code Editor
> **React · TypeScript · Node.js · Express · ShareDB · PostgreSQL · Docker · Gemini**

A real-time collaborative code editor supporting concurrent multi-user editing — think Google Docs, but for code, with AI review built in.

- 🖱️ Live cursor sync with concurrent multi-user editing via ShareDB
- 🕵️ Plagiarism detection with similarity scoring
- 🤖 Google Gemini integration for inline AI code review (bugs + style)
- 🐳 Dockerized backend deployed on Render with PostgreSQL
